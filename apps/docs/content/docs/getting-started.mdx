This guide walks you through creating a project, generating an API key, and sending your first event.

## 1. Create an account

You can use the managed instance at [https://up.linus.my](https://up.linus.my) or [self-host](/docs/self-host) your own.

Sign in with GitHub. Upstream uses GitHub OAuth for authentication.

## 2. Create a project

After signing in, create a new project from the dashboard. Projects are the top-level container for your events and API keys.

## 3. Create an API key

Open your project settings and generate an API key. Give it a descriptive name like `production-api` or `local-dev`. Copy the key value — you will only see it once.

## 4. Install the SDK

```bash
npm i @uplabs/sdk
```

## 5. Send an event

```ts
import { Upstream } from '@uplabs/sdk';

const up = new Upstream({
  apiKey: 'YOUR_API_KEY',
});

await up.events.ingest({
  title: 'Hello, World!',
  icon: '😁',
});
```

Run the script and check your dashboard — the event should appear immediately.

## 6. (Optional) Configure a custom host

If you are self-hosting, point the SDK at your own instance:

```ts
const up = new Upstream({
  apiKey: 'YOUR_API_KEY',
  host: 'https://upstream.example.com',
});
```
