This guide explains how to run the entire Upstream monorepo locally.

## Prerequisites

- Node.js 18+
- npm
- PostgreSQL (local or Docker)
- GitHub OAuth app for authentication

## Clone and install

```bash
git clone https://github.com/linuskang/up
cd up
npm install
```

## Configure the web app

```bash
cp .env.example apps/web/.env
```

Edit `apps/web/.env` with your database URL and OAuth credentials. Make sure `BASE_URL` and `BETTER_AUTH_URL` point to `http://localhost:3000`.

## Generate the Prisma client

```bash
cd apps/web
npx prisma generate
```

## Run migrations

```bash
npx prisma migrate dev
```

## Start the dev server

From the repository root:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
.
├── apps/
│   ├── docs/          # Documentation site (this site)
│   ├── marketing/     # Landing page
│   ├── playground/    # SDK playground
│   └── web/           # Main Upstream application
├── packages/
│   ├── contracts/     # Shared TypeScript types
│   ├── sdk/           # @uplabs/sdk
│   ├── ui/            # Shared UI components
│   ├── eslint-config/ # Shared ESLint config
│   └── typescript-config/ # Shared TS config
```

## Useful commands

| Command | Description |
| ------- | ----------- |
| `npm run dev` | Start all apps in development mode. |
| `npm run build` | Build all packages and apps. |
| `npm run lint` | Run ESLint across the monorepo. |
| `npx prisma migrate dev` | Run Prisma migrations. |
| `npx prisma studio` | Open Prisma Studio. |
