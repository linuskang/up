Upstream is a simple, open-source event logging platform built for SaaS projects. It gives you a clean dashboard, push notifications, webhooks, and a tiny SDK so you can start tracking product events in minutes.

## Why Upstream?

Most logging tools are either too heavy or too expensive for side projects and small SaaS apps. Upstream tries to hit the sweet spot:

- **Tiny SDK** — one dependency, one method call.
- **Beautiful UI** — view, search, and filter events in real time.
- **Push notifications** — get alerted on your phone for critical events.
- **Webhooks** — forward events to your own endpoints by category.
- **Self-hostable** — run everything on your own infrastructure with Docker.

## Use cases

Upstream works best for product and business events such as:

- User signups and activations
- Reports, flags, or moderation events
- Payment and subscription lifecycle events
- Custom alerts you want to monitor actively

## How it works

1. Create a project on an Upstream instance (ours or yours).
2. Generate an API key for that project.
3. Install [`@uplabs/sdk`](https://www.npmjs.com/package/@uplabs/sdk) in your app.
4. Call `up.events.ingest(...)` whenever something interesting happens.
5. View the event in the dashboard or receive a push notification.

```ts
import { Upstream } from '@uplabs/sdk';

const up = new Upstream({
  apiKey: process.env.UPSTREAM_API_KEY,
});

await up.events.ingest({
  title: 'New signup',
  icon: '🎉',
  category: 'user',
});
```
