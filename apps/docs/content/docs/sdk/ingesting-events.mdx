---
title: Ingesting Events
description: Learn how to send rich events with categories, fields, actions, and more.
---

Events are the core of Upstream. An event can be as simple as a title and icon, or as rich as a structured object with fields, actions, and push notifications.

## Basic event

```ts
await up.events.ingest({
  title: 'New signup',
  icon: '🎉',
});
```

## Event context

The full shape of an event is defined by the `EventContext` interface:

```ts
interface EventContext {
  title: string;
  icon?: string;
  description?: string | null;
  category?: string | null;
  fields?: { title: string; value: string }[];
  actions?: {
    title: string;
    variant: 'primary' | 'secondary' | 'ghost';
    url: string;
  }[];
  data?: unknown;
  contextId?: string | null;
  contextStart?: boolean;
  pushNotify?: boolean;
}
```

Only `title` is required.

## Rich example

```ts
await up.events.ingest({
  title: 'Payment received',
  icon: '💰',
  description: 'A customer just paid their invoice.',
  category: 'billing',
  fields: [
    { title: 'Customer', value: 'Acme Corp' },
    { title: 'Amount', value: '$49.00' },
    { title: 'Plan', value: 'Pro' },
  ],
  actions: [
    {
      title: 'View invoice',
      variant: 'primary',
      url: 'https://dashboard.example.com/invoices/123',
    },
  ],
  data: {
    invoiceId: 'inv_123',
    customerId: 'cus_456',
  },
});
```

## Categories

Categories group related events in the dashboard and can trigger webhooks. Pick consistent category names across your app.

```ts
await up.events.ingest({
  title: 'Report submitted',
  category: 'moderation',
});
```

## Context IDs

Use `contextId` to link a sequence of events together. A `contextStart: true` event marks the beginning of a flow; later events with the same `contextId` are nested under it.

```ts
const contextId = crypto.randomUUID();

await up.events.ingest({
  title: 'Checkout started',
  contextId,
  contextStart: true,
});

await up.events.ingest({
  title: 'Payment confirmed',
  contextId,
});
```

## Push notifications

Set `pushNotify: true` to send a push notification to subscribed devices. Useful for events you want to know about immediately.

```ts
await up.events.ingest({
  title: 'Server error',
  description: 'Checkout service returned 500',
  pushNotify: true,
});
```

## Response

`ingest` resolves with the created event:

```ts
const event = await up.events.ingest({ title: 'Hello' });

console.log(event.id); // uuid of the stored event
```
