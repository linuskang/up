---
title: Configuration
description: Configure the Upstream SDK for managed or self-hosted instances.
---

The `Upstream` constructor accepts a `Configuration` object.

## Options

```ts
interface Configuration {
  /** Your project API key. Required. */
  apiKey: string;
  /** URL of the Upstream instance. Defaults to https://up.linus.my */
  host?: string;
}
```

## Managed instance

If you are using [https://up.linus.my](https://up.linus.my), you only need an API key:

```ts
const up = new Upstream({
  apiKey: process.env.UPSTREAM_API_KEY!,
});
```

## Self-hosted instance

Point the SDK at your own server by setting `host`:

```ts
const up = new Upstream({
  apiKey: process.env.UPSTREAM_API_KEY!,
  host: 'https://upstream.example.com',
});
```

The SDK will send requests to `${host}/api/v1/log`.

## Environment variables

A common pattern is to keep the API key in an environment variable and instantiate the SDK once per process:

```ts
// lib/upstream.ts
import { Upstream } from '@uplabs/sdk';

export const up = new Upstream({
  apiKey: process.env.UPSTREAM_API_KEY!,
  host: process.env.UPSTREAM_HOST,
});
```

Then import `up` wherever you need to log an event.

## TypeScript

The SDK is written in TypeScript and ships with type definitions. You can import the configuration and context types directly:

```ts
import type { Configuration, EventContext, IngestedEvent } from '@uplabs/sdk';
```
