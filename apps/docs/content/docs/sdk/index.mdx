The `@uplabs/sdk` package is the official way to send events to Upstream from any Node.js or edge runtime.

## Requirements

- Node.js 18 or later
- A valid Upstream API key

## Install

```bash
npm i @uplabs/sdk
```

## Import

```ts
import { Upstream } from '@uplabs/sdk';
```

## Basic usage

```ts
const up = new Upstream({
  apiKey: process.env.UPSTREAM_API_KEY!,
});

await up.events.ingest({
  title: 'User signed up',
  icon: '🎉',
});
```

## Modules

The SDK exposes a single `Upstream` class. All event-related methods live under `up.events`:

| Member | Type | Description |
| ------ | ---- | ----------- |
| `up.events.ingest(event)` | Method | Sends a single event to Upstream. |
