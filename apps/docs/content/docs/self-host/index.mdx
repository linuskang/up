Upstream is designed to be self-hosted with Docker and PostgreSQL. This section explains how to deploy your own instance.

## Requirements

- Docker and Docker Compose
- A PostgreSQL 17 database (the compose file includes one)
- A domain name and reverse proxy (recommended for production)
- OAuth credentials from GitHub

## What's included

The default `docker-compose.yml` spins up two services:

- `app` — the Upstream Next.js web application.
- `db` — a PostgreSQL 17 database with a persistent volume.

## Quick start

1. Clone the repository:

```bash
git clone https://github.com/linuskang/up
cd up
```

2. Copy the environment file and fill in the values:

```bash
cp .env.example .env
```

3. Start the services:

```bash
docker compose up -d
```

4. Apply database migrations:

```bash
docker compose exec app npx prisma migrate deploy
```

5. Open `http://localhost:3000`.

## Production checklist

Before exposing your instance to the world:

- [ ] Use a strong `BETTER_AUTH_SECRET`.
- [ ] Replace placeholder VAPID keys with your own.
- [ ] Configure GitHub OAuth with your domain.
- [ ] Set up HTTPS with a reverse proxy.
- [ ] Use a managed PostgreSQL instance instead of the container for reliability.
- [ ] Restrict `ALLOW_SIGNUP` if you do not want public registration.
