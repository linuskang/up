---
title: Environment Variables
description: Configure your self-hosted Upstream instance.
---

Upstream is configured through environment variables. Copy `.env.example` to `.env` and fill in the values before starting the container.

## Required variables

| Variable | Description | Example |
| -------- | ----------- | ------- |
| `DATABASE_URL` | PostgreSQL connection string. | `postgresql://upstream:upstream@db:5432/upstream` |
| `BASE_URL` | Public URL of your instance. | `https://upstream.example.com` |
| `BETTER_AUTH_SECRET` | Random secret for Better Auth. Generate with `openssl rand -hex 32`. | `...` |
| `BETTER_AUTH_URL` | Same as `BASE_URL`. | `https://upstream.example.com` |
| `GITHUB_CLIENT_ID` | GitHub OAuth app client ID. | `...` |
| `GITHUB_CLIENT_SECRET` | GitHub OAuth app client secret. | `...` |

## Email variables

| Variable | Description | Example |
| -------- | ----------- | ------- |
| `RESEND_API_KEY` | Resend API key for transactional email. | `re_...` |
| `RESEND_EMAIL_FROM` | Sender address. | `noreply@upstream.example.com` |

## Push notification variables

| Variable | Description | Example |
| -------- | ----------- | ------- |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | VAPID public key for web push. | `BCPa...` |
| `VAPID_PRIVATE_KEY` | VAPID private key for web push. | `...` |

Generate a VAPID key pair with:

```bash
npx web-push generate-vapid-keys
```

## Other variables

| Variable | Description | Example |
| -------- | ----------- | ------- |
| `CRON_SECRET` | Secret required to call the retention cron endpoint. | `...` |
| `ALLOW_SIGNUP` | Whether new users can register. Set to `false` to disable public signup. | `true` |

## Example `.env`

```bash
DATABASE_URL="postgresql://upstream:upstream@db:5432/upstream"
BASE_URL="https://upstream.example.com"

BETTER_AUTH_SECRET="YOUR_BETTER_AUTH_SECRET"
BETTER_AUTH_URL="https://upstream.example.com"

GITHUB_CLIENT_ID="YOUR_GITHUB_CLIENT_ID"
GITHUB_CLIENT_SECRET="YOUR_GITHUB_CLIENT_SECRET"

RESEND_API_KEY="re_..."
RESEND_EMAIL_FROM="noreply@upstream.example.com"

CRON_SECRET="YOUR_CRON_SECRET"
ALLOW_SIGNUP="true"

NEXT_PUBLIC_VAPID_PUBLIC_KEY="YOUR_PUBLIC_VAPID_KEY"
VAPID_PRIVATE_KEY="YOUR_PRIVATE_VAPID_KEY"
```

## GitHub OAuth setup

1. Go to **Settings → Developer settings → OAuth Apps** on GitHub.
2. Click **New OAuth App**.
3. Set **Authorization callback URL** to `https://upstream.example.com/api/auth/callback/github`.
4. Copy the Client ID and Client Secret into your `.env`.
