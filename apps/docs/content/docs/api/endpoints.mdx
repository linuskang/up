## Ingest an event

```http
POST /api/v1/log
```

### Headers

| Header | Value |
| ------ | ----- |
| `x-api-key` | Your project API key. |
| `Content-Type` | `application/json` |

### Body

```ts
{
  title: string;
  icon?: string;
  description?: string | null;
  category?: string | null;
  fields?: { title: string; value: string }[];
  actions?: { title: string; variant: "primary" | "secondary" | "ghost"; url: string }[];
  data?: unknown;
  contextId?: string | null;
  contextStart?: boolean;
  pushNotify?: boolean;
}
```

### Example

```bash
curl -X POST https://up.linus.my/api/v1/log \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Test Event",
    "icon": "~",
    "category": "test"
  }'
```

### Response

```json
{
  "code": 200,
  "success": true,
  "message": null,
  "data": {
    "id": "...",
    "projectId": "...",
    "title": "Test Event",
    "icon": "~",
    "category": "test",
    "contextStart": false,
    "pushNotify": false,
    "createdAt": "2026-08-08T00:00:00.000Z"
  }
}
```

## Other endpoints

The following endpoints are used by the dashboard and require a session cookie from Better Auth. They are not intended for external service-to-service use:

| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| `GET` | `/api/v1/project` | List your projects. |
| `POST` | `/api/v1/project` | Create a project. |
| `GET` | `/api/v1/project/:id` | Get a project. |
| `GET` | `/api/v1/project/:id/events` | List project events with filters and pagination. |
| `GET` | `/api/v1/project/:id/logs` | List request logs. |
| `GET` | `/api/v1/project/:id/keys` | List API keys. |
| `POST` | `/api/v1/project/:id/keys` | Create an API key. |
| `DELETE` | `/api/v1/project/:id/keys` | Delete an API key. |
| `GET` | `/api/v1/project/:id/categories` | List event categories. |
| `GET/POST` | `/api/v1/project/:id/webhooks` | Manage webhooks. |
| `GET` | `/api/v1/account/usage` | Current usage stats. |
| `GET` | `/api/v1/account/activity` | Recent account activity. |
| `POST` | `/api/v1/cron/retention` | Run retention cleanup (requires `CRON_SECRET`). |

For the most up-to-date request and response shapes, inspect the route handlers in `apps/web/app/api/v1`.
