---
title: Authentication
description: Authenticate with Upstream using API keys.
---

Upstream uses project-scoped API keys. Include the key in the `x-api-key` header on every request.

## API keys

API keys are created from the project settings page in the dashboard. Each key belongs to a single project and tracks its own usage.

## Header

```http
x-api-key: YOUR_API_KEY
```

## Example with curl

```bash
curl -X POST https://up.linus.my/api/v1/log \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title":"Hello, World!"}'
```

## Security

- Store API keys in environment variables or a secrets manager, never in source control.
- Rotate keys periodically from the dashboard.
- If a key is compromised, disable or delete it immediately.

## Failed authentication

If the key is missing or invalid, the API returns:

```json
{
  "code": 401,
  "success": false,
  "message": "Invalid API key",
  "data": null
}
```
