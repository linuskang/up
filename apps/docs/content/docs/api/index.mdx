Upstream exposes a small REST API. Most integrations use the SDK, but you can call the API directly from any language or tool.

## Base URL

- Managed instance: `https://up.linus.my`
- Self-hosted: your own `BASE_URL`

## Response format

All endpoints return JSON with a consistent envelope:

```json
{
  "code": 200,
  "success": true,
  "message": null,
  "data": {}
}
```

- `code` mirrors the HTTP status code.
- `success` is `true` for 2xx responses and `false` otherwise.
- `message` may contain a human-readable explanation.
- `data` contains the payload when present.

## SDK vs. API

For TypeScript and JavaScript projects, the SDK handles headers, JSON serialization, and error parsing for you. Use the API directly when:

- You are building in a language without an SDK.
- You need to build custom tooling or integrations.
- You want to prototype with `curl`.
